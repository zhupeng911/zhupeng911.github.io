# zhupeng911.github.io

+朱鹏的个人主页，展示教育背景、Java 后端开发经历、项目实践、学术成果和技术能力。

This repository contains Peng Zhu's personal homepage.

The site is built with Vue 3, TypeScript, Vite, and Vuetify.

## Local development

Install dependencies with npm install, then start the development server with npm run dev.

## Production build

Run npm run build to create the production bundle. The site can be deployed to GitHub Pages with npm run deploy.
